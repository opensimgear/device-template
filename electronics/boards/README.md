# Boards

- [Starter v0.1.0](starter/0.1.0/README.md): the single current STM32G0B1CBT6 device design, with eight analogue inputs, 24 digital lines and I²C expansion; matching firmware target `starter_g0b1cb_v0_1_0` and configurable profiles.

Production and home-milling fabrication variants share this circuit. Earlier circuits remain in Git history. [PCB versioning](../VERSIONING.md) defines semantic versions; keep 0.1.0 fixed while the project is pre-live. Maintain firmware and mechanical compatibility explicitly.
