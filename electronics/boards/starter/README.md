# Starter board

[Rev A](rev-a/README.md) is the first implemented STM32G0B1CBT6 starter. It includes USB-C HID/CDC wiring, two parallel powered CAN pass-through connectors, power regulation/selection, SWD, a test button and LED. KiCad sources and a BOM are present; PCB routing and physical qualification remain open.

This is a module starting point, independent of Lite/Pro mechanical editions. It does not select the five-port gateway platform or approve a final CAN cable/pinout.
