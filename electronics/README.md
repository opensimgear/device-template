# Electronics

The [starter board](boards/starter/rev-a/README.md) now contains editable KiCad 10 project/schematic/PCB files, local libraries, BOM, pinout, front/back copper previews and validation results. It is a **routed prototype** with zero copper DRC violations, unconnected items or schematic mismatches; manufacturer and physical review are still required. Each PCB revision lives under `boards/<board>/<revision>`; mechanical editions can share it.
